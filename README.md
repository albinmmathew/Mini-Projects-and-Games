# Mini Projects and Games

Welcome to the Mini Projects and Games repository! This repo contains a collection of small yet fun projects implemented using various data structures and programming techniques.

---

## 🟦 Projects Included

### 1. Minesweeper Game (C)

A classic implementation of Minesweeper in C, featuring:
- Use of data structures: stack, linked list, 2D array, and structure
- Console-based gameplay
- Custom board initialization
- Challenge your logic and memory!

### 2. Number Sliding Game 4x4 (Java)

Experience the classic sliding puzzle game in a 4x4 grid:
- Implemented in Java using a fixed initial 2D matrix board
- Move the blank space by inserting the number you want to swap with the blank
- Simple controls and compact gameplay loop

**How to Play:**
1. The game displays a 4x4 grid with numbers and one blank space.
2. To move, enter the number adjacent to the blank that you wish to swap.
3. Repeat until you solve the puzzle!

## 🚀 Getting Started

### Minesweeper Game (C)
1. Navigate to the Minesweeper game source file.
2. Compile using a C compiler, e.g.:
   ```
   gcc minesweeper.c -o minesweeper
   ```
3. Run the executable:
   ```
   ./minesweeper
   ```

### Number Sliding Game 4x4 (Java)
1. Navigate to the Java source file for the sliding game.
2. Compile with:
   ```
   javac NumberSlidingGame.java
   ```
3. Run the game:
   ```
   java NumberSlidingGame
   ```
